KARTHIK H. — PERSONAL PORTFOLIO
================================

FILES
- index.html: website content and structure
- style.css: layout, colors, responsive design, and animations
- script.js: mobile navigation, reveal effects, project filters, and small interactions
- assets/vision-vault-background.webp: Vision Vault cinematic background
- assets/karthik-portrait.webp: supplied creator portrait used in the hero

HOW TO OPEN ON WINDOWS
1. Extract the ZIP file to a folder.
2. Open the folder.
3. Double-click index.html. It should open in your default browser.
4. For editing, open the folder in Visual Studio Code (recommended) or Notepad.

HOW TO EDIT
- Change your introduction and About section in index.html.
- Edit project cards in the section with id="projects".
- Update skills in the section with id="skills".
- Replace milestone text with real achievements in the section with id="achievements".
- Update the YouTube and Vision Vault links if they change.
- Add a public email address or professional profile in the Contact section only if you want it visible.
- Change colors near the top of style.css in the :root section.

IMPORTANT
- The website uses two local image assets in the assets folder. Keep that folder alongside index.html, style.css, and script.js.
- Google Fonts require an internet connection; the page will use a fallback font if offline.
- This is a front-end static website. It does not include a server, database, login, or contact-form delivery.
- Before publishing, review every line and replace sample/ongoing project descriptions with accurate details.
- Do not publish your home address, private phone number, school timetable, passwords, or other private information.

PUBLISHING
You can publish the three files with a static hosting provider such as GitHub Pages, Netlify, or Cloudflare Pages. Create an account and follow that provider's current deployment instructions. A custom domain is optional.
